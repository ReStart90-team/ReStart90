# ReStart90｜九十天重生

[English](README.md)

把生活还给自己。Take your life back.

ReStart90 帮助刚出院的下肢截肢患者和家属，用 90 天把生活一步一步交还给患者。每项生活能力分四级：家属替我做 → 家属陪我做 → 家属在旁保护 → 我自己能做到。

> 所有病历和数据都是合成的。ReStart90 不做诊断，不修改医嘱，不决定负重进度。

## 运行

需要 Node.js 22.13 或更高版本（使用内置的 `node:sqlite`）。

```bash
npm install
npm start
```

打开 http://localhost:3090。第一次启动会自动生成示例患者林凯（27 岁，左侧小腿截肢，回家第 9 天，带前 8 天的记录）。

- 接入 AI：设置环境变量 `ANTHROPIC_API_KEY` 后，出院小结提取和口语解析会调用 Claude（默认 `claude-opus-5-5`，可用 `RESTART90_MODEL` 修改）。已开启 `fallbacks: "default"`：模型拒答时，服务端会自动换用备用模型。
- 不接 AI：自动进入离线模式。示例病历使用预生成结果，其他文字使用规则提取。红旗关键词规则无论是否接入 AI 都会运行。强制离线：`RESTART90_OFFLINE=1 npm start`。
- 测试：`npm test`
- 清空数据库：`npm run reset`

## 设计依据

每个页面的结构都依据心理学和逻辑结论来安排，例如：
- 脚手架理论
- 自我决定理论
- 执行意图
- 目标梯度
- 依赖-支持循环
- 金字塔原理

完整说明和参考文献见 [DESIGN.md](DESIGN.md)。网页右上角的"设计依据"开关，会把这些依据直接标注在页面对应的位置上，适合给评委和导师讲解。首页只保留一句话和林凯的一张任务卡，研究依据放在"为什么有效"页。

## 五步演示脚本

| 步骤 | 页面 | 操作 | 观众看到什么 |
|---|---|---|---|
| 1 资料进入 | 新建档案 | 使用示例出院小结，然后点"开始提取" | 原文中高亮出五个字段，用户逐条确认后生成计划 |
| 2 今日分工 | 患者、家属、康复人员 | 依次切换三个角色 | 同一天的三张清单：患者三件事、家属帮多少和放手什么、康复人员待确认事项 |
| 3 自主权变化 | 患者 → 家属 → 康复人员 | 患者洗漱点"做到了"，再点"我愿意试试"；家属点"允许"；康复人员点"确认升级" | 四步升级依次亮起，洗漱从"家属替我做"变成"家属陪我做"，家属端同步变成"陪他完成" |
| 4 一次变化 | 底部演示栏 | 点"疼痛上升和情绪低落" | 系统暂缓床椅转移的升级 |
| 5 安全升级 | 底部演示栏 | 点"伤口异常" | 相关任务暂停，所有升级停止，生成联系医生摘要，康复人员端收到提醒 |
| 收尾 | 90天地图 | 查看地图和复盘 | 灰色（家属替我做）在减少，黄色（我自己能做到）在增加，红旗暂停的日子标红 |

底部演示栏的"重置"可以回到初始状态。每位访问者都有自己的一份演示数据，评委之间互不影响；"重置"只重置你自己的那一份。

## 结构

```
server.js          HTTP 服务和 REST API（无框架）
lib/content.js     中英双语内容库：4 个阶段（含通过和暂停条件）、6 项生活能力 × 4 级、红旗规则、训练、同伴故事（模板 v0.1，待临床审核）
lib/engine.js      规则引擎：今日清单、四步升级、退级、红旗停止、医生摘要、长期没有进展和分歧、路标助手、复盘、90 天地图
lib/ai.js          AI 层：出院小结提取、口语转信号、倾听回复，附带离线兜底
lib/samples.js     合成出院小结和预生成提取结果
lib/db.js          SQLite 表结构
public/            单页前端（原生 JS，中英切换）
test/              规则引擎测试
```

## 安全规则（代码里写死，不交给 AI）

- 升级条件：一级升二级需要连续完成 2 次，更高等级需要连续完成 3 次，并且没有红旗信号。
- 每一次升级都走四步：系统建议 → 患者愿意试 → 家属确认家里条件 → 康复人员最后确认。患者没有点头时，康复人员无法确认。
- 新建的档案必须由康复人员确认计划；确认前所有能力按最保守的等级执行。
- 路标助手从不说"这很正常"：命中红旗规则时直接转给专业人员，其余情况说明"我不能判断"，并提供发给康复人员的入口。
- 疼痛或情绪出现波动时，系统暂缓所有升级。
- 出现红旗信号时，暂停相关任务，停止所有升级，并生成联系医生摘要。摘要里的数字全部来自数据库。
- 胸痛、气短，或有伤害自己的想法，会暂停全部任务，并显示 120 和 12356 热线。

## 本轮视觉与瑞瑞增强

此次基线为上传的完整 V0.2 项目，不覆盖 GPT 中的视觉预览。患者、家属、康复人员、90 天地图、每日记录、周月复盘和安全规则继续使用原来的页面、API 与 SQLite 数据表。`public/motion.css` 是独立深色视觉层，`public/galaxy.js` 是本地 Three.js 粒子场；点击光波只负责反馈，不拦截业务控件。

核心公开标语为“把生活还给自己。 / Take your life back.”，差异为“一个人也能开始。 / Start on your own.”。瑞瑞使用已有形象，输入框可以直接输入任意内容，原四入口是快捷提示。自由对话使用原接口的 `{text,lang,history}`，history 条目为 `{role,text}`。对话不会擅自改完成状态；记录、缩小任务和求助动作沿用明确确认的旧接口。

配置见 `.env.example`。`MODEL_PROVIDER=deepseek`、`DEEPSEEK_API_KEY`、`DEEPSEEK_BASE_URL` 和 `DEEPSEEK_MODEL` 只放服务器环境，不能写进前端。无密钥或超时时标记“演示模式”；红旗先运行规则，模型不能更改医嘱。文字型 PDF 用服务器 `pdftotext`（`poppler-utils`）先提取，继续原五字段确认；扫描件无法可靠读取时提示粘贴文字或使用演示病历。

开场与第二屏独立放映区分开。第二屏使用指定金色花树封面，点击封面或黄色按钮有声播放74.6秒成片，支持手机内联与原生播放控件，不自动播放。影片和封面位于`public/assets/`，随源码包一起提供；影片为1080p网页压缩版、保留原音轨。人物与剧情是概念表达，不是患者康复结果证据。

增强版运行：`npm ci` 后 `HOST=0.0.0.0 PORT=3000 npm start`；`npm test` 运行医疗规则、认证、存储和前端隔离回归。字体与 Three.js 已本地化。原合成演示的SQLite仍仅在当前实例保存，沿用7天闲置清理；登录后建立的私人档案使用下文的独立持久存储，不受演示重置影响。

## 手机号密码与私人档案（当前增强版）

私人账号采用手机号＋密码；不使用假验证码，不会把手机号标为已验证。首次注册会返回一次性展示的恢复码，请本人妥善保存。账号会话使用HttpOnly Cookie，密码以scrypt加盐哈希保存。请在正式HTTPS网址的独立浏览器窗口登录；内嵌预览的第三方Cookie限制可能影响会话保留。

私人数据与公开合成演示分开。只有登录账户可新建私人病例；原五项医嘱来源逐条确认和专业计划确认规则不变。私人病例以单病例SQLite快照保留原引擎数据结构，并在MySQL中加密持久保存；不是把容器临时SQLite当长期云存。登录同一账号可在手机、电脑读取同一份私人记录。不同账号必须通过持有人创建的一次性邀请加入指定病例；权限在服务器校验。手机号与专业资质未经平台核验，请自行核对真实授权和医嘱。

后台必须配置项目专属`RESTART90_DATA_SECRET`（32字节以上，建议使用随机64字符十六进制），只通过受保护环境面板保存，开发与正式环境使用同一值。不得提交到源码、Git、聊天或日志。密钥更换需要数据重加密迁移，不可为已有私人数据随意换钥匙。`DATABASE_URL`由项目持久库提供。首次部署前运行`node scripts/init-accounts.js`，只进行增量建表；启动时也会检查准备状态，未就绪时私人账户失败关闭、公开演示保持可用。

私人记录按建档记录日和固定时区流转，保留原始出院日期，禁止演示式手动推进或重置私人病例。私人聊天按账号＋病例加密隔离，不自动继承别人的本地演示记忆。病例共享备注不是私聊，也不表示自动拨打电话或发送短信。医疗模板仍待专业审核，不能替代医生。原匿名浏览器合成演示保留7天清理，不擅自转入某个登录账号。
