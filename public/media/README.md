# Promo film

Put the finished promo film here and the site picks it up on the next server start:

| File | What it is |
|---|---|
| `the-next-step.mp4` | The film (H.264 MP4) |
| `poster.jpg` | Optional still shown before playing |
| `the-next-step.en.vtt` | Optional English subtitles |
| `the-next-step.zh.vtt` | Optional Chinese subtitles |

Until `the-next-step.mp4` exists, the landing page and the story page show a placeholder.
Large video files make the git repo heavy; consider hosting the MP4 elsewhere if it is over ~50 MB.
